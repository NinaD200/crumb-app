Crumb 1.3.2 — Interactive crop scanner

Take a photo directly from Crumb or choose from Photos. Drag over a region, select Title / Ingredients / Instructions, then tap Read selected area. Reuse the same image to scan other regions. Text appends to the editable import box. Fill recipe fields from text to apply.

Install: replace index.html, sw.js, manifest.webmanifest and icon.svg in GitHub Pages repo. Export a recipe backup first. No recipe data schema changes.

OCR requires an internet connection to load Tesseract and language files. iPhone Safari testing is still needed.
